# Wireless 101 · Module 1: How wireless communication works

- **Audience**: first-year undergraduates, no radio background; high-school algebra and logarithms
- **Occasion and time**: lecture, 50 minutes, quiz inside the slot
- **Goal**: students can answer how far, how fast and how many for any wireless system, and do the arithmetic
- **Promise**: By the end you can say how far a signal goes, how fast it can carry data and how many users can share the air (slide 1)
- **Story**: Every wireless system answers the same three questions (how far, how fast, how many), and a few formulas answer them
- **Fence**: Antenna gain focuses power; it does not create it (slide 10). Shannon is a ceiling, not an achieved rate (slide 20 notes)
- **Look**: studio, theme fonts, lang en; the teaching theme the manual names for Wireless 101
- **Sources**: wireless-101-module-1.md
- **Placeholders**: three image placeholders (slides 2, 10, 25); receiver sensitivity −90 dBm is the module's own example value
