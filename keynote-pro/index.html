Keynote Pro

A one-file HTML presentation format that looks like a well-made Keynote or PowerPoint deck. A fixed 16:9 stage, six themes, twelve font pairings, builds, Magic Move, outline, presenter view, marker, PDF export and a checker. No framework, no build step, opens from a file.

What is in it

  • 20 layouts that auto-fit their content: title, section, statement, agenda, bullets, two-column, image left and right, full-bleed, big number, stats, chart, comparison, timeline, process, quote, code, team, diagram, closing.
  • Builds (fade, rise, scale, wipe, draw, count, list, code focus) and Magic Move between slides, on the Web Animations API. Reduced motion is honoured.
  • Presenter tools: outline, overview, presenter window with notes and timer, marker with colours and eraser, black and white screens, touch swipe.
  • Live theme and font switching (press S, hover to preview) and a documented token contract for adding themes.
  • check.mjs: overflow, text size, contrast and console errors for every slide in every theme, in about two seconds.
Personal project by Hisham Abuella. Illustrations in the examples were generated locally and are illustrative only; products, companies and figures in the sample decks are fictional.
