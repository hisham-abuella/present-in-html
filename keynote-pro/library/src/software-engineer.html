The fix

One fetch per key, everyone else waits

    async function getProfile(id) {
      const hit = await cache.get(id)
      if (hit) return hit
      // single flight: share one in-flight fetch per key
      if (!inflight.has(id)) {
        inflight.set(id, db.load(id).finally(() => inflight.delete(id)))
      }
      return inflight.get(id)
    }

What worked, what did not

Worked

  • Runbook found the pool graph in two minutes
  • Load shedding bought time
  • Replay harness reproduced it first try

Did not

  • Page threshold was 8 s, not 1 s
  • No jitter on TTLs
  • Dashboards showed averages only

Keep it about the system, not people.

Action items

  • Add TTL jitter. Plus or minus 10 percent.
  • Page at p99 above 1 s for five minutes.
  • Ship single-flight in the shared client library.
  • Add a stampede test to CI.
