Three rules for every account

In English

  • A strong, different password for each account
  • Never share a code that was sent to you
  • Ask before you click a link

بالعربية

  • كلمة مرور قوية ومختلفة لكل حساب
  • لا نشارك أبدًا الرمز الذي وصلنا
  • نسأل قبل أن ننقر على أي رابط

Read each rule in both languages; ask a parent to repeat one in their own words.

الرسالة التي تطلب منك الاستعجال تستحق أن تتوقف عندها.

المحتالون يعتمدون على الخوف والسرعة.

Arabic slide. Scammers rely on urgency; pause before acting.

عند وصول رسالة مشبوهة

أربع خطوات بسيطة

  1. توقّف

    لا تنقر ولا ترد.

  2. تحقّق

    اتصل بالجهة من رقمها الرسمي.

  3. أبلغ

    أخبر أحد أفراد الأسرة.

  4. احذف

    ثم احظر المرسل.

Four steps: stop, verify, report, delete. Steps run right to left in the Arabic slide.

اختبر فهمك

وصلتك رسالة تطلب رمز التحقق الخاص بك. ماذا تفعل؟

  1. أرسله بسرعة
  2. لا أشاركه مع أحد
  3. أرسله إلى صديق
  4. أرد وأسأل عن السبب

Answer B: never share a verification code. Ask for a show of hands first.
