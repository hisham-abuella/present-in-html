A Claude Code plugin

Presentations, written in HTML.

Give Claude a topic, an outline, documents, data or links. Get a designed slide deck: one file that opens in any browser, presents itself, and prints to PDF.

Four skills, one deck

Claude picks the right one from what you ask. Each loads only when it is needed, so the plugin adds about 734 tokens to a session.

01 / make

Make

present-in-html

Writes the deck from your material in a look chosen for your audience, with speaker notes, then runs the checker.

Turn q3-report.pdf into a 10-minute board deck
02 / edit

Edit

edit-deck

Opens a click-and-type editor for wording and notes. Save writes the same file back.

Let me fix the wording myself
03 / review

Review

review-deck

Checks timing, jargon, story and sources against the audience and the time slot.

Will this fit in 15 minutes for managers?
04 / publish

Publish

publish-deck

Puts the deck and its images on GitHub Pages and returns a link to share.

Put my deck online so I can send a link

What every deck can do

The engine, the theme and the slides live in one HTML file. Nothing to install to present it.

32 themesSix core looks and 26 made for a profession, each with fonts and a slide recipe.
28 layoutsFrom title and chart to case review, quiz, ask and materials board. Text fits itself.
Presenter windowNotes, the next build, a timer or countdown. Press P.
Builds and Magic MoveLists reveal, numbers count, charts draw, objects morph between slides.
Arabic and RTLEvery layout mirrors; bilingual decks have their own look.
Checked before deliveryOverflow, text size, contrast and missing notes, in every theme.

Install

Two commands in Claude Code, then ask for a presentation.

As a plugin

Recommended. Updates arrive with /plugin update.

/plugin marketplace add hisham-abuella/present-in-html
/plugin install present-in-html@present-in-html-marketplace

Then just ask

Or call a skill directly, like /present-in-html:review-deck.

Make a 10-minute deck for our Q3 board review.
Revenue was $4.2M, up 18%.

Without the plugin system

Copies the four skills into ~/.claude/skills/.

git clone https://github.com/hisham-abuella/present-in-html.git
cd present-in-html && ./install-skill.sh

For the checker

Playwright, installed once outside the plugin folder.

mkdir -p ~/.kp-tools && cd ~/.kp-tools
npm i playwright && npx playwright install chromium
